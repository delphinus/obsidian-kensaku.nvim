INTRODUCTION				         *obsidian-kensaku-introduction*

obsidian-kensaku.nvim adds Romaji search capabilities to |obsidian.nvim|. It
provides two commands:

- |:ObsidianKensaku| searches note contents (like |:ObsidianSearch|)
- |:ObsidianQuickKensaku| searches notes by file name
  (like |:ObsidianQuickSwitch|)

Romaji input is converted to regex using a built-in pure Lua migemo engine
(ported from jsmigemo), enabling you to search Japanese text without
switching input methods. No external binaries or separate processes are
required.

REQUIREMENTS				         *obsidian-kensaku-requirements*

- Neovim >= 0.10.0
- epwalsh/obsidian.nvim
    https://github.com/epwalsh/obsidian.nvim
- nvim-telescope/telescope.nvim
    https://github.com/nvim-telescope/telescope.nvim
- A migemo compact dictionary file (see |obsidian-kensaku-dictionary|)
- fdschmidt93/telescope-egrepify.nvim (optional, recommended)
    https://github.com/fdschmidt93/telescope-egrepify.nvim

DICTIONARY				              *obsidian-kensaku-dictionary*

This plugin uses a compact binary dictionary from oguna/migemo-compact-dict-
latest. The dictionary is auto-detected from the following locations:

1. `~/.cache/kensaku.vim/migemo-compact-dict` (cached by kensaku.vim)
2. `stdpath("data") .. "/migemo-compact-dict"`

If you have previously used kensaku.vim, its cached dictionary is reused
automatically. Otherwise, download it manually: >bash
    curl -fLo "$(nvim --headless \
            -c 'echo stdpath("data")' -c 'qa!' 2>&1)/migemo-compact-dict" \
      https://github.com/oguna/migemo-compact-dict-latest/releases/\
    download/v0.2/migemo-compact-dict
<
You can also specify a custom path via |obsidian-kensaku-dict_path|.

  https://github.com/oguna/migemo-compact-dict-latest

INSTALLATION				              *obsidian-kensaku-install*

Example configuration with lazy.nvim: >lua
    {
      "epwalsh/obsidian.nvim",
      dependencies = {
        "nvim-lua/plenary.nvim",
        "delphinus/obsidian-kensaku.nvim",
      },
      opts = {
        callbacks = {
          post_setup = function(client)
            require "obsidian-kensaku"(client)
          end,
        },
      },
    }
<
IMPORTANT: You must call this plugin in `opts.callbacks.post_setup`.

If you want to customize the dictionary path: >lua
    {
      "epwalsh/obsidian.nvim",
      dependencies = {
        "nvim-lua/plenary.nvim",
        {
          "delphinus/obsidian-kensaku.nvim",
          opts = {
            dict_path = "/path/to/migemo-compact-dict",
          },
        },
      },
      opts = {
        callbacks = {
          post_setup = function(client)
            require "obsidian-kensaku"(client)
          end,
        },
      },
    }
<

==============================================================================
COMMANDS				             *obsidian-kensaku-commands*

:ObsidianKensaku [query]			      *:ObsidianKensaku*

	Search vault note contents with Romaji. Works like |:ObsidianSearch|
	but converts Romaji input to regex for Japanese text matching. If
	[query] is given, it is used as the initial search query.

:ObsidianQuickKensaku				         *:ObsidianQuickKensaku*

	Search vault notes by file name with Romaji. Works like
	|:ObsidianQuickSwitch| but converts Romaji input to regex for
	Japanese text matching.

==============================================================================
OPTIONS					              *obsidian-kensaku-options*

Options can be passed to the setup function or as `opts` in lazy.nvim: >lua
    require("obsidian-kensaku").setup {
      dict_path = "/path/to/migemo-compact-dict",
      picker = "egrepify",
    }
<
						         *obsidian-kensaku-dict_path*
dict_path ~
	Type: `string`
	Default: (auto-detected)

	Path to the migemo-compact-dict file. If not specified, the plugin
	searches common locations automatically
	(see |obsidian-kensaku-dictionary|).

						    *obsidian-kensaku-query_filter*
query_filter ~
	Type: `fun(query: string): string`
	Default: built-in Lua migemo

	A custom function that takes a Romaji query string and returns a
	PCRE regex string for grep-based search. Overrides the built-in
	migemo engine.

	Example: >lua
	    {
	      query_filter = function(query)
	        return some_way_to_create_regex(query)
	      end,
	    }
<
						           *obsidian-kensaku-picker*
picker ~
	Type: `"default"` | `"egrepify"`
	Default: `"default"`

	The telescope picker to use. Set to `"egrepify"` to use
	telescope-egrepify.nvim, which provides better regex highlighting.

						        *obsidian-kensaku-previewer*
previewer ~
	Type: `fun(): table`
	Default: `nil`

	A function that returns a custom telescope previewer. When set, it
	is used for all picker commands. For example, md-render.nvim can
	render Markdown in the preview window.

	  https://github.com/delphinus/md-render.nvim

	Example: >lua
	    {
	      previewer = function()
	        return require("md-render.telescope").previewer()
	      end,
	    }
<
